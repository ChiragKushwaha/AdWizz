Questions

Why isn't it on the Play Store?

Google Play doesn't allow apps that block ads in other apps. That's why ad blockers like this are distributed directly. Every release here is built from the open-source code on GitHub and signed with the same key, and Android refuses updates signed by anyone else.

Is it really a VPN? Does my traffic go somewhere?

It uses Android's VPN feature only to see DNS look-ups (the "phone book" of the internet) on your own device. Ad and tracker names get a "doesn't exist" answer; everything else goes straight to your chosen DNS server. Your browsing never passes through anyone else's server.

Why do some YouTube or Instagram ads still show?

Those ads come from the same servers as the videos and posts themselves, so blocking them would break the app. Every DNS-based blocker has this limit.

Ads still show in my browser

Check that Android's Private DNS is set to Off or Automatic, and that Chrome's "Use secure DNS" isn't set to a custom provider. AdWizz shows a warning if Private DNS is bypassing it.

Can it protect devices on my hotspot?

Android never routes hotspot traffic through a VPN, but AdWizz's Devices tab shows a QR code that sets up ad-blocking DNS on iPhones, Macs and other devices in a few taps.

Privacy

AdWizz has no account and no servers of its own. The list of blocked and allowed domains is kept only in memory on your phone, and your browsing and DNS look-ups are never sent anywhere. It downloads public blocklists and checks this site for updates.

To learn how the app is used, AdWizz sends anonymous usage statistics (such as app opens and the device model) to Google Firebase Analytics. It never sends the sites or apps you use, and the advertising ID is turned off.
